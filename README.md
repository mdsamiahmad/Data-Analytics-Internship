# Data Analytics Internship

A collection of data analytics projects completed during my Data Analyst Internship at **Renu Sharma Foundation**.

The internship involved practical work with **Excel, SQL, Python, Pandas, NumPy, Power BI, and data visualization** across sales, customer, retail, churn, and movie-rating datasets.

## 🛠️ Tools & Technologies

- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **SQL**
- **Microsoft Excel**
- **Power BI**
- **Jupyter Notebook**

## 📂 Projects

### Task 1 — Sales Performance Tracker

**Tools:** Excel

Created a sales dashboard using:

- Pivot Tables
- Charts
- Basic Excel formulas
- Sales performance analysis

**Deliverable:** Excel dashboard with charts and summary sheet.

---

### Task 2 — Customer Database Queries

**Tools:** SQL

Used SQL to extract customer and sales insights, including:

- Top 5 spending customers
- Total sales by region
- Average order size
- Customer-related sales insights

**Deliverable:** SQL queries with result screenshots.

---

### Task 3 — Data Cleaning & Manipulation

**Tools:** Python, Pandas, NumPy

Cleaned a dataset by:

- Handling missing values
- Removing duplicates
- Correcting inconsistent formats
- Transforming data for analysis

**Deliverables:**

- Jupyter Notebook
- Cleaned CSV
- Before/after comparison

---

### Task 4 — Retail Data Integration

**Tools:** SQL, Excel, Python

Worked with a retail dataset using multiple analytics tools:

- Imported data into SQL
- Exported data to Excel
- Cleaned and processed data using Python
- Documented tool-wise usage and insights

**Deliverable:** Brief report covering the workflow and insights.

---

### Task 5 — Telecom Churn Analysis

**Tools:** Python, Pandas, NumPy, Matplotlib

Performed Exploratory Data Analysis (EDA) on customer churn data.

Analysis included:

- Correlation analysis
- Outlier identification
- Churn pattern analysis
- Data visualization
- Insight generation

**Deliverables:**

- Jupyter Notebook
- Visualizations
- Insight Summary PDF

---

### Task 6 — Movie Ratings Analysis

**Tools:** Python, Pandas, NumPy, Matplotlib

Created visualizations to analyze movie ratings, including:

- Genre distribution
- Average rating by genre
- Yearly trends
- Most popular year
- Other rating-related patterns

**Deliverable:** Visual report containing 5+ charts.
