# Customer Database Queries

## Overview

A SQL-based customer and sales analysis project focused on extracting
useful insights from the Superstore dataset using SQL queries.

## Tools Used

- MySQL
- SQL

## Dataset

**Superstore.csv**

The dataset contains sales and customer-related information used
to perform SQL-based analysis and extract business insights.

## Analysis

The project includes SQL queries to analyze:

- Top 5 spending customers
- Total sales by region
- Average order size
- Customer purchasing behavior
- Sales-related insights

## SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- Aggregate Functions
- JOINs
- Subqueries
- DISTINCT
- ROUND

## Project Files

- `Superstore.csv` — dataset used for the analysis.
- `Customer_Database_Queries_Task_2.sql` — SQL queries used for the analysis.
- `Customer_Database_Queries_Task_2.pdf` — SQL queries with result screenshots and outputs.

## Results

The PDF contains the executed SQL queries along with their
corresponding results and screenshots.
