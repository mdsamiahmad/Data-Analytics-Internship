# Data Cleaning & Manipulation

## Overview

A Python-based data cleaning and manipulation project focused on
preparing a dirty dataset for further analysis.

## Tools Used

- Python
- Pandas
- NumPy
- Jupyter Notebook

## Data Cleaning

The project involved identifying and handling common data-quality
issues, including:

- Missing values
- Duplicate records
- Incorrect or inconsistent data formats
- Data transformation
- Data type handling

## Workflow

1. Loaded the raw dataset using Pandas.
2. Inspected the dataset structure and data types.
3. Identified missing values and duplicate records.
4. Cleaned and transformed the data using Pandas and NumPy.
5. Validated the cleaned dataset.
6. Compared the dataset before and after cleaning.
7. Exported the cleaned dataset as a CSV file.

## Project Files

- `Data_Cleaning.ipynb` — Jupyter Notebook containing the complete cleaning and manipulation process.
- `cleaned_data.csv` — cleaned dataset after applying the transformations.
- `Before_After_Comparison.pdf` — comparison of the dataset before and after cleaning.
